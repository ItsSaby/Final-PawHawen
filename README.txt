# PAWHAVEN 🐾

PAWHAVEN is a pet shop website that we developed as our Web Development Final Project.

We wanted to create a simple and convenient website where people can find pet products, learn more about different pets and explore adoption information.

## Our Team

This project was developed by three students:

- **Miras Kamaladin** – Home and Shop pages
- **Ayaulym Amankeldykyzy** – Our Pets and Adoption pages
- **Dias Aibekuly** – About Us and Contact pages

We worked together on improving the website and adding new features for the final version.

## What We Have Done

Our website includes:

- Home page with information about our pet shop.
- Shop page with different products for pets.
- Our Pets page with pet information.
- Adoption page.
- About Us page.
- Contact page.
- Login and Registration.
- User Profile.
- Shopping Cart.

## Main Features

During the development, we added several interactive features:

- Light and Dark Mode.
- Registration and Login using Local Storage.
- Personal Profile page.
- Shopping Cart where users can add and remove products.
- Product search and category filtering.
- Product ratings.
- Form validation.
- API integration.
- Responsive design for different screen sizes.

## Changes in the Final Version

After our previous assignment, we continued working on the project and made some improvements:

- Changed the fonts to Montserrat and Poppins.
- Added more product images to the Shop page.
- Removed repeated products.
- Fixed problems with images not displaying.
- Improved the Shopping Cart.
- Added Login and Registration functionality.
- Created a separate Profile page.
- Improved the layout and navigation.
- Organized HTML, CSS and JavaScript into separate files.

## Technologies

We used the following technologies:

- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- Local Storage
- Public API

## How to Run

1. Download the project.
2. Open the folder in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Open the website in your browser.
